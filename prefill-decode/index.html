    UNDER THE HOOD

    Why the two passes feel different

    Prefill processes the prompt

    The prompt is already known, so a full prefill can process its token positions together. The causal mask lets each position attend only to itself and earlier positions. The last prompt position supplies the next-token logits, and the model can emit its first token from those logits.

    Prefill contributes to time to first token, along with work such as scheduling and tokenization.

    Decode extends the sequence

    Each standard decode pass takes the previously emitted token as input. It computes that token’s query, key, and value at each layer and reads the saved keys and values for earlier positions. The resulting logits are used to choose the next token.

    Repeated decode passes determine the time between output tokens. With full attention, each pass attends to more positions as the sequence grows.

    What the cache saves

    The cache stores keys and values by position and layer. It avoids recomputing them for earlier tokens, but the new query still attends to the cached positions. A generated token joins the cache only when it goes through a forward pass.

    Visible query–key pairs in the demo count unmasked attention entries. They do not measure runtime or memory use.
